# Gustoso — вёрстка PSD-макета

Адаптивная одностраничная вёрстка макета `01.psd` (Gustoso) на **Flexible Box Layout Module**.
Каждая секция свёрстана как независимый блок по методологии BEM: блок можно убрать,
переставить или переиспользовать, не затрагивая остальные.

## Состав

```
gustoso/
├── index.html              семантическая разметка HTML5
├── css/style.css           стили: базовые, блоки, адаптив
├── js/main.js              интерактив: меню, карусель, рейтинг, карточки, диалог
├── img/                    изображения, извлечённые из макета
└── README.md
```

## Детали оформления

* **Коллаж:** фотографии обрезаны по контуру (без белых полей), занимают всю площадь плитки,
  а рамка — тонкая белая линия в 10 px от краёв, нарисованная поверх фотографии.
* **Бейдж «Tastes so good!»:** полупрозрачная заливка, фигура `01_0001s_0001s_0000_Vektor-Smartobjekt`
  с двойной обводкой, текст с мягким светлым ореолом.
* **Карточки завтраков:** у первой в круге крендель, у второй и третьей — виноград
  (`…food---fruit-grape`); иконки обрезаны по контуру и отцентрованы.
* **Пшеница:** `01_0001s_0003s_0002s_0000_Vektor-Smartobjekt` продублирована, одна копия
  отзеркалена и соединена со второй основаниями — «корона» над Toast & Jam и Muffins.
* **Сэндвич:** мельница увеличена и стоит вплотную над заголовком; блок Ready in 50
  без боковых рамок (из фона удалена тень карточки), статистика идёт сплошной колонкой.

## Flexbox

`display: flex` использован для всех раскладок:

* шапка — `justify-content: space-between`, `align-items: center`;
* первый экран — вертикальный flex-столбец по центру;
* «Art of cakes» — две колонки (`space-between`), галерея — `flex-wrap: wrap`;
* «Tasty pancakes» — фото + карточка (`align-items: stretch`, равная высота);
* завтраки — меню + стопка карточек (`space-between`);
* сэндвич — преимущества + фото (`flex-start`), статистика — `flex-direction: column`, строки `flex: 1`;
* подвал — три flex-элемента;
* модальное окно и его кнопки.

## Интерактив (js/main.js)

* бургер-меню на планшете и телефоне;
* стрелки карусели блинов переставляют круглые миниатюры;
* пять звёзд рейтинга: клик выставляет оценку, наведение показывает предпросмотр;
* три карточки завтраков перелистываются стрелками (стопка с анимацией);
* кнопки **Read** и **Full recipe** открывают диалог с рецептом (`<dialog>` + `showModal`);
* иконки соцсетей открывают twitter.com, facebook.com и instagram.com в новой вкладке.

## Адаптивность

Контрольные точки: **1440, 1240, 1100, 992, 768, 520, 380 px**.

* до 1100 px — бургер-меню вместо горизонтальной навигации;
* до 992 px — секции складываются в одну колонку, преимущества сэндвича — в ряд;
* до 768 px — мобильная типографика, карточки на всю ширину, статистика в строку;
* до 520/380 px — уменьшенные заголовки, карусель и бейдж.

## Типографика

Шрифты из макета, подключаются из Google Fonts:

* **Alegreya** 400/700 — заголовки секций, меню, подписи, кнопки;
* **Playfair Display** 700 — заголовок первого экрана;
* **Mulish** 400 — основной текст (замена Proxima Nova);
* **Great Vibes** — рукописная цитата (замена Scriptina, логотип — PNG из макета).

Для каждого семейства задан локальный fallback-стек.

## Запуск

Открыть `index.html` в браузере. Внешние шрифты подгружаются из Google Fonts;
без сети страница остаётся рабочей за счёт fallback-шрифтов.
